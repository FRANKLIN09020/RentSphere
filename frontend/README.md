# RentSphere – Smart Property and Rental Management System

RentSphere is a smart property and rental management interface for handling organizations, users, properties, and rental operations.

## Available Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Project Notes

- The application connects to the RentSphere backend API.
- Set `VITE_API_BASE_URL` when the API is not running on `http://localhost:8080`.
- Production files are created in the `dist` folder after running `npm run build`.
