# RentSphere Final Report Screenshot Checklist

Use this list to prepare Chapter 5.2 of the report.

## Before capturing

- Run the backend and frontend using production-like demonstration data.
- Use a 1440×900 browser viewport where possible.
- Hide bookmarks, developer tools and unrelated browser tabs.
- Never expose API keys, JWTs, passwords, OTPs or database connection strings.
- Use the generated files in `frontend/public/demo-images` for clean listing data.
- Capture both an administrator/owner workflow and a tenant workflow.

## Required captures

1. Login page.
2. Administrator dashboard.
3. Property records.
4. Building records.
5. Unit availability records.
6. Tenant records.
7. Agreement records.
8. Tenant apartment browser.
9. Visit request and approval status.
10. Manager approval decision screen.
11. Outstanding invoice before payment.
12. Razorpay test checkout (do not expose credentials).
13. Successful transaction history with no obsolete pending row.
14. Complaint creation and manager status.
15. Deposit dispute record.
16. Rent increase notice and tenant response.
17. Real-time notification menu.
18. Profile showing organization name.
19. Dark theme.
20. Mobile/responsive layout.

## Exporting the report

1. Open `RentSphere-Final-Project-Report.md` in VS Code.
2. Preview the Markdown and verify Mermaid diagrams render.
3. Insert the captured screenshots below their corresponding Chapter 5.2 captions.
4. Export with a Markdown PDF extension, browser Print → Save as PDF, or paste into Word while preserving heading styles.
5. Update the generated table of contents and page numbers after final pagination.
